Caliber Agent

The multi-model OpenRouter terminal agent that routes every sub-task to the best AI model.

Install in one command

curl -fsSL https://raw.githubusercontent.com/webscout9-png/caliber-agent/main/scripts/install.sh | bash

Requires Python 3.10+. Then run caliberagent.

Why Caliber is different

  • One provider only — OpenRouter (single API key → hundreds of models)
  • Task decomposition + smart routing — coding goes to Claude, reasoning to strong reasoners, search to online models, etc.
  • Best or Custom mode — auto-pick top models or map your own (free models clearly marked)
  • Effort levels — low → ultra control depth and cost
  • Plan / Build modes — plan first, then execute
  • Clean terminal UI with live usage bar, sessions, and slash commands

Quick start

  1. Run the install command above
  2. caliberagent
  3. /provider → paste your OpenRouter key
  4. Type your request or use /model, /effort, /plan, /build
